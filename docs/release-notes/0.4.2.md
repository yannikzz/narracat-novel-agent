这一版主要修**第三方中转渠道下 Agent 调不动工具**的问题，顺带缩小了 Windows 的更新包。

- **走中转网关、或用较弱模型时，Agent 读不了、写不了文件**：症状是 Agent 一直报「工具不存在」、或者反过来劝你「项目未初始化，请去重建」。根因是模型照说明书写出的工具名和运行时登记的名字对不上，现在由 App 统一归一。如果你之前只有直连官方渠道才能正常写章节，这一版可以再试试中转渠道
- **不再出现「请去跑初始化」这种点不动的提示**：读不到文件时 Agent 会如实说明本次无法继续，不会再建议你重新建一部书
- **Windows 更新包从 244MB 缩到十几 MB**：差量更新在 Windows 上终于真的生效，这一版之后的升级会快很多（从 0.4.1 升到这一版仍是全量，再下一版开始才是差量）
- **粘贴参考作品时空标题会被当场拦住**：以前能点保存、然后在后台报错；现在标题为空时保存按钮不可用，回车也不会提交
- **任务失败时会记下失败原因的类型**（匿名统计的一部分，不含任何小说内容），方便我们看出用户最常卡在哪一类问题上
