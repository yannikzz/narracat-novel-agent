# 专业版来了，书一键带过去

这一版修好几处写作中会卡住的问题，并介绍免费的 NarraCat 专业版。

## 新增

- 介绍 NarraCat 专业版：好在哪、书怎么带过去，书架顶栏和「设置 → 关于」随时能看

## 改进

- 同一种失败连续 3 次自动停下后，提示改为从中断处继续写，或把日志报告给我

## 修复

- 已经有正文的章，不会再被「写本章」直接覆盖
- 完成进度和正文对不上时，打开作品会按已写完、已记入记忆的章自动补上进度
- 用第三方 OpenAI 兼容服务时，不再频繁报「找不到工具」后自动停下
- 直接改了章纲文件后再写或再审，用的是改过的章纲，不再按旧的判
- 人物同一项状态不再同时留着新旧两个值
- 设定了状态词表的书，规划时能查到人物当前状态，不再重复安排已经发生的转折
