这一版最重要的一条是：**升级不会再删你的小说**。

- **升级只清理 App 自己的文件**：如果你把小说保存在 App 的安装目录里（比如装在 `D:\NarraCat`、小说根目录也设在这里），旧版本升级时会把整个目录连同小说一起删掉，且不进回收站。现在安装器只删自己装进去的文件，其余原样保留；万一升级中途出错，你的文件会被放回原处。**如果你正好是这种情况，升级前请先备份一份。**
- **书架能认出「找不到的书」**：外置盘拔了、文件夹被移走，书架会明确显示这本书找不到了、去哪儿找，并且可以从书架移除——移除只是从列表里去掉，不会动你的任何文件。文件夹还在但内容不完整的书，会和「找不到」分开显示。
- **生成大纲对长篇更稳**：大纲改成一卷一卷提交，卷数多的书不会再因为一次交太多而失败，已有的卷也不会被覆盖掉。
- **Agent 写不下去时会明确停下**：以前遇到输出被截断，Agent 会反复重试白等很久；现在会立刻停下来并告诉你可以怎么办。
- **出问题更容易查**：运行过程现在会记进日志，你用「设置 → 关于 → 报告问题」提交时，我们能直接看出是哪一步、跑了多久、为什么失败。
