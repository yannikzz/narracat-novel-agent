# 升级不再删你的小说

这一版最重要的一条：升级只清理 App 自己的文件，不会再删到你的小说。

## 新增

- 书架能认出「找不到的书」，告诉你去哪找，也可以从书架移除（不动任何文件）

## 改进

- 生成大纲改为一卷一卷提交，长篇不再因一次交太多而失败，已有的卷不被覆盖
- 用「报告问题」提交后，我们能看出卡在哪一步、为什么失败

## 修复

- Windows 上小说存在安装目录里时，升级会连小说一起删掉；现在只删 App 自己的文件
- Agent 写不下去时会立即停下并告诉你怎么办，不再反复重试白等

## 备注

- 如果你的小说存在 App 安装目录里，升级前请先备份一份
