# 关键节点你能插手

这一版让作者在几个关键节点能自己插手，并修好了写正文被截断的问题。

## 新增

- 正文润色：用你自己的提示词跑几版润色，逐版对照原稿再决定采不采用
- 「下一步」常驻侧边栏，在任何页面都能看到创作走到哪、下一步做什么
- 「设置 → 关于」可以一键生成脱敏诊断，提交问题报告
- 「设置 → 模型服务」里每个模型可以自己填输出上限

## 改进

- 创作流程补上「设定」这一步，开写前 Agent 会先跟你确认一句
- 模型目录新增 DeepSeek V4 Flash 等 5 款，已下线的会标出

## 修复

- GLM、Kimi 等渠道写正文不再被截断，万一被截断会自动重试一次
- Agent 提问时内容区会显示待答问题和「去回答」，不再点了没反应
