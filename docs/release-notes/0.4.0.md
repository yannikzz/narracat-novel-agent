这一版让作者在几个关键节点能**自己插手**了。

- **正文润色通道**：写完的章节可以用你自己的提示词跑几版润色，逐版对照原稿再决定采不采用；出厂不带任何模板，怎么改由你说了算
- **「下一步」常驻侧边栏**：不管在哪一页都能看到创作链走到哪、下一步该做什么；创作链补上了「设定」这一步
- **Agent 提问时不再「点了没反应」**：内容区会显示待答的问题和「去回答」，开写前 Agent 会先问你一句
- **修复 GLM / Kimi 等渠道写正文一直被截断**：输出上限按模型抬高，「设置 → 模型服务」里每个模型可以自己填；被截断时自动重试一次
- **报告问题**：「设置 → 关于」一键生成脱敏诊断（版本、系统、最近日志）并提交到 GitHub；主进程现在有日志文件了，出问题能查
- **模型目录更新**：新增 deepseek-v4-flash、claude-opus-5 / sonnet-5、MiniMax-M2.7、glm-4.7-flash；已下线的模型会在列表里标出来
