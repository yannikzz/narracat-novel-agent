# 加入匿名使用统计

这一版加入匿名使用统计，用来判断哪些功能真的有人用、哪些该改。

## 新增

- 匿名使用统计：只上报功能名称、成败与耗时区间
- 首次启动有一屏说明，可以选择不参与，之后在「设置 → 安全与项目」随时关闭

## 备注

- 小说正文、章节标题、大纲、人物设定、书名与 API Key 一个字都不传
- 数据只关联本机随机生成的 ID，与账号、设备无关，无法反查到人
- 完整事件清单与自查方式见 [FAQ](https://github.com/yannikzz/narracat-novel-agent/blob/main/docs/faq.md#narracat-会收集我的数据吗)
