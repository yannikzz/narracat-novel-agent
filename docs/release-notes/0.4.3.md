# 重写不再清后文

这一版修好了重写章节的几个老问题，并加上网络代理设置。

## 新增

- 「设置 → 模型服务」底部可以填网络代理，本机地址与本地模型始终直连

## 改进

- 同一种失败连续 3 次会自动停下，提示你重试或换模型，不再白白消耗额度

## 修复

- 重写中间某一章，不再清掉后面各章的记忆和进度
- 重写出的正文也要过字数等交付检查，不达标会先补写
- 写章中途中断后，作品页能找回那一章
- 使用 opencode go 订阅时，不再所有请求都报 400
- 编辑弹窗里粘贴长文本不再撑出窗口，保存按钮始终可见

## 备注

- 已受重写问题影响的书，这一版不会自动修复
- 你自己手改的章节不受字数检查影响
- 感谢 @huihuisang 和 @maozuxiao 的报告与贡献
