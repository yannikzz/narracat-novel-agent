这一版主要修**重写章节**相关的几个问题，并加上了**网络代理**设置。

- **重写中间某一章，不再把后面各章的记忆和进度一起清掉**：以前重写第 N 章，会顺带清空它之后所有章节的摘要、记住的事实和完成进度，「写下一章」会指向已经写过的章节。现在只重来这一章，后面各章不动。已经受影响的书，这一版不会自动修复
- **重写出的正文也要过字数等交付检查**：以前重写稿太短、或者像被截断，也照样算写完；现在不达标会先让 Agent 补写，补不好就停下来告诉你。你自己手改的章节不受影响
- **写章中途中断后，作品页能找回那一章**：中断后再去跑设定、或重写别的章，不会再把「写到一半」的记录冲掉
- **设置里可以填网络代理**：「设置 → 模型服务」页面底部新增「网络代理」，填 `http://127.0.0.1:7890` 这样的地址即可，留空就是不用。本机地址始终直连，本地模型不受影响
- **Agent 反复以同样的方式失败时会自动停下**：以前遇到模型一直传错参数，会一直重试、白白消耗额度；现在连续 3 次同样的失败就停下，并告诉你可以重试或换一个模型 / 渠道
- **支持 opencode go 订阅**：以前所有请求都会报 400，用不了
- **长文本不会再把编辑弹窗撑出窗口**：在写手人设、作者要求等弹窗里粘贴很长的内容时，保存按钮始终可见
