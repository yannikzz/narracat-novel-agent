# 写作过程少踩坑

把写作流程里那些看不见、却一直拖后腿的毛病挨个修掉，让创作更可靠。

## 新增

- 新建小说默认全自动；想逐步确认，在书架那本书的「更多」菜单里切换
- 自定义渠道支持 OpenAI 兼容协议，能接入更多模型服务（来自社区提案）

## 改进

- 连续性审校能看到本章所有出场角色，不再只拿到主角一张卡
- 提高单次输出上限，长章节与大段改写更少被截断
- 打磨环节关掉多余的思考过程，更快也更省额度

## 修复

- 安装包里查找文件、搜索内容一直失败，写章节时不再反复报错
- 中途被打断时如实报错，不再假装写完、悄悄跳过打磨
- 过程里出错的地方如实显示「失败」，不再显示成「已跳过」
- 项目文件损坏时告诉你能做什么，不再甩一串看不懂的报错

## 备注

- 版本号从 0.1.x 改为 0.2.x；之前收不到更新提示的，这一版起恢复正常
