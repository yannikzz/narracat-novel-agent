# Windows 版来了

NarraCat 不再只属于 Mac：Windows 版开放下载，与 Mac 版同一套引擎、同样的功能。

## 新增

- Windows 客户端开放下载，支持 Windows 10/11 64 位，安装时可自选目录
- Windows 窗口顶栏按系统习惯重做，最大化、分屏、贴边与原生窗口一致

## 改进

- 遇到崩溃或卡住时自动留下现场记录，反馈问题更容易查清

## 修复

- 用 OpenAI 兼容协议接入的模型服务，部分能力悄悄失效的问题已修复

## 备注

- 运行要求：Windows 10/11（64 位），或 Apple 芯片（M1 及以上）的 Mac
- 往后两个平台同步发版
